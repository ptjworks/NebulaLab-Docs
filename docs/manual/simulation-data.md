# 模拟数据收集（待完善）

本模块待完善。以下说明预期页面信息、资料准备和目标流程；具体入口、支持格式及字段以之后的发布版本为准。

## 目标与数据范围

关联材料或研究任务，整理模拟的输入、方法、运行条件与输出，让模拟结果有明确来源，并可与实验数据进行比较。

## 预期页面内容

| 内容 | 需要准备的资料 |
| --- | --- |
| 研究对象 | 材料组成、结构文件、对应任务或样品 |
| 计算条件 | 软件与版本、方法、边界条件、关键参数 |
| 运行记录 | 任务标识、时间、状态与日志 |
| 结果 | 性能或结构结果、单位、结果文件与解析说明 |

## 规划流程

整理输入与条件 → 导入运行记录及结果 → 核对单位与来源 → 关联研究对象 → 提交数据中心。

此流程为建设目标，尚未提供完整操作教程。支持哪些模拟软件与解析格式，需要后续确认。

## 与其他模块的关系

模拟数据将作为专业数据库的一类来源，为材料模型提供可核对的数据；实验验证结果应保留独立来源，避免把预测或模拟值混同为实测值。
