# 数据中心（搭建中）

统一数据中心正在搭建，目标是汇聚实验、模拟与文献数据，保留结构化字段、版本、来源和访问权限。以下实验室接入、上报与检索说明以已安装版本及实际服务器配置为准；模拟与文献数据的统一接入待完善。

数据中心用于承接实验室的结构化记录、相关文件和历史修订。桌面端完成日常记录与计算，实验室服务提供上报、检索、预览和受控获取。

## 本地工作与实验室部署

桌面端在用户电脑上维护实验记录、处理数据和保存工程。团队按实际部署配置接入实验室服务器；具体服务器部署和开放能力需由实验室维护者确认。

本地工程、长期实验库和服务器记录各有职责，不应把数据中心理解成所有业务记录的实时双向同步。

## 上报实验数据

1. 按软件内流程接入实验室，核对账号、设备及成员身份。
2. 选择待上报记录，检查配方、样品、测试和文件来源是否完整。
3. 确认需要提交的内容，在提交资格及资源权限满足时上报。
4. 查看提交状态与修订信息，保留可追溯的来源。

## 检索与获取

1. 按样品、测试项目或指标等实际可用条件检索。
2. 预览获准范围内的记录和文件，检查来源及版本。
3. 在权限允许时获取文件，按任务加入数据处理。
4. 使用历史数据进行比较时，核对仪器、单位及实验条件。

## 访问权限

软件功能许可、管理员角色和资源访问权限分别判断。上传不代表向全组共享；查看、导出和再次发布也分别授权。当前云端成果为创建者私有，管理员角色不能自动覆盖数据所有权。

详见[数据中心与权限](./data-center)、[授权说明](./pro)。
