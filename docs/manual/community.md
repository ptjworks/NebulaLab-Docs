# 社区与模板

把已经验证过的处理方法保存为资源，后续处理同类数据时可以复用。团队成员也可以在获得相应权限后使用这些方法。

## 数据处理流程模板

模板保存处理步骤和参数，帮助减少重复配置。使用时先核对数据类型、列、单位和导入设置，再检查处理结果是否符合本次实验。

同一套流程可以提高操作的一致性，但不能代替研究者判断样品是否可比、参数是否合适。

## Origin 模板与主题

Origin 绘图模板和主题帮助复用图形布局与样式。交接前确认需要导出的分组、X/Y 列和模板，具体效果也取决于模板与本机 Origin 环境。

## 科研脚本与插件

科研计算脚本用于复用计算方法；插件用于扩展支持的数据导入、处理及其他工具能力。是否支持某台仪器或某种算法，应以实际资源说明和运行环境为准。

脚本和插件不因出现在社区中就适用于所有科研任务。使用前核对来源、依赖、版本和参数。

## 公开与团队内部资源

- 公开社区资源按其公开范围浏览和使用。
- 团队内部模板、脚本等资源在获得授予的权限后向相应成员开放。
- 登录或加入团队，不等于能获取全部资源。
- 资源交流与实验室科研数据库是不同的体系；发布模板不应附带未经许可的实验内容。

官网介绍资源类型与使用方式；实际浏览、获取和使用在软件内按权限执行。
