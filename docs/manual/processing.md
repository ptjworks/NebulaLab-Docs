# 数据统一后处理

将同类测试文件按统一方法处理，保存输入来源、分组、处理顺序与参数。先验证方法适用性，再批量应用。

## 页面与工作区

数据处理工作区包括导入与解析、数据列与分组、处理流程、结果预览及导出等区域。界面位置随安装版本变化，先核对数据和处理对象，再执行具体操作。

## 导入并核对

1. 从电脑、本地样品或已接入的数据中心选择文件。
2. 检查分隔符、表头、数据区与缺失值，确认解析结果。
3. 选择 X/Y 列，核对物理量与单位。
4. 按样品、变量或重复测试组织分组，保留来源对应关系。

## 配置与批量处理

1. 为一条代表数据配置适用的裁剪、平滑、基线或归一化步骤。
2. 检查步骤顺序与参数，比较原始数据和处理结果。
3. 确认方法后保存为模板，再应用到同类文件。
4. 核对每组结果，记录异常与处理失败原因。
5. 保存工程及输入来源，导出结果或交接 Origin。

## 模板复用与扩展

模板保留方法和参数，不能代替对单位、列映射及仪器条件的核对。扩展插件的算法与可用范围，以安装版本和已安装插件为准。共享时注明适用条件、版本与资源授权范围。
