# 记录实验过程

样品是实验过程的关联入口。围绕同一样品保存对应配方、制备步骤、参数和图像，使后续测试能够回到当时的实验条件。

## 页面与记录组成

样品详情中维护编号与名称、基础配方及实际组成、制备步骤、工艺备注和附件。当前版本的步骤主要以文本记录，部分组成与工艺具有结构化字段。

## 操作步骤

1. 创建样品，填写能区分本次实验与批次的编号和名称。
2. 选择基础配方版本，核对实际组分及用量。
3. 按执行顺序记录混合、成型、固化等步骤，注明实际调整。
4. 记录温度、时间、压力、转速等适用参数，同时填写单位。
5. 在当前版本可用的附件或外观记录入口添加过程图与制备图，注明步骤、时间和观察内容。
6. 对照实际实验检查内容，确认制备并保留快照。

## 图像与参数如何配合

一张图应能说明它对应哪个样品、哪个步骤及何种现象。照片作为记录依据；保存图片不等于软件已自动识别工艺参数，也不替代文字或结构化参数。

## 纠正与追溯

发现已确认记录有误时，使用安装版本提供的副本、修订或版本操作，说明变更原因。保留原始快照，避免用新的配方解释旧的实验。
