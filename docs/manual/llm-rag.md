# Large Language Model (LLM)+RAG知识助手

**建设状态：规划中。目的：让人更高效地使用已有的知识。**

基于已沉淀的专业数据库，结合大语言模型与检索增强生成（RAG），查看相关实验数据、搜索相似实验方案，整理专业领域的实验方案报告。下面是预期页面与流程，当前没有可执行的完整操作入口。

## 预期页面内容

| 区域 | 目标内容 |
| --- | --- |
| 研究问题 | 研究目标、材料体系、实验约束与所需输出 |
| 检索范围 | 获准使用的实验、模拟、文献记录与数据库版本 |
| 相似记录 | 对应条件、结果、差异及可核对来源 |
| 方案报告 | 证据摘要、候选方案、条件、引用与待确认事项 |

## 目标流程

1. 描述研究问题、目标及实验约束，选择获准范围的数据。
2. 检索相关记录与相似实验方案，检查来源及适用条件。
3. 由模型结合检索依据整理报告，并区分已有事实与建议。
4. 研究者审阅引用、方法与实验条件，再确定执行方案。
5. 将实际实验及结果记录回数据库，保留方案与来源关系。

## 数据与结果的使用

检索结果需要保留来源、版本和原文位置。信息不足时应明确缺失依据，实验方案报告需要研究者核对，不能把模型生成文字当成已经验证的实验事实。

## 与 ML 材料智能体的区别

LLM+RAG 帮助理解和复用已有知识；[ML 材料智能体](./ml-agent)从结构化数据学习关系，进行性能预测、筛选与逆向设计。两者的数据来源与访问权限均需明确。
