# 样品管理：实验过程参数与图像

每个物理样品是一条关联线索：它引用实验配方，承接制备步骤、过程参数、图像、测试原始文件和后续分析成果。

## 记录制备过程 {#preparation}

1. 创建样品，填写编号与名称，选择对应基础配方版本。
2. 检查本次组分及用量，记录实际调整与原因。
3. 按先后顺序填写混合、成型、固化等实际步骤。
4. 在适用字段或步骤备注中记录温度、时间、压力、转速等参数及单位。
5. 通过附件、外观记录等当前版本可用入口补充过程图与样品制备图。图像建议写明步骤、拍摄时间和观察内容。
6. 核对完成后确认制备，保留当时的配方和过程快照。

当前制备步骤主要以文本记录，部分组成和工艺有结构化字段；图片作为记录依据，不自动转成工艺参数。需要改变已锁定记录时，使用软件提供的副本或版本操作，保留原始依据。

## 关联表征测试 {#testing}

1. 在样品“测试与表征”中新增记录，选择测试项目。
2. 填写方法、仪器、测试日期、操作人及条件。
3. 输入结果指标、单位和质量状态，例如拉伸强度、模量或特定条件下的残重。
4. 添加仪器原始文件、曲线、图像等附件，关联到本次测试。
5. 重复测试分别保存；有排除数据时注明原因。

结果指标和原始文件分别保存。红外可保留光谱与特征峰；热重残重应注明温度和气氛。测试项目不同，所需指标也不同，不能用同一个数值替代完整测试依据。

## 从测试到处理及成果

将所需测试文件添加到[数据处理](./workflow)，核对列映射、分组和单位后使用已验证的流程。完成 Origin 作图后，支持成果归档的版本可以保存工程和图像并关联参与样品。

在 Origin 外部修改后，需要手动更新成果版本。详见[Origin 与成果关联](./experiment-workflow#origin)。
