# 全链路数据管理

将实验记录与文件放入一致的关联结构，保留来源、单位、版本与权限，让数据能够被查找、理解、复核和复用。

## 身份与命名

物料、配方、样品、测试和成果各自拥有可区分的标识。文件命名可包含样品编号、测试项目、日期与重复序号；名称便于辨认，实际关联仍以记录为准。

## 来源与关系

1. 物料保留批次、物性及资料来源。
2. 样品关联实际采用的配方版本和制备快照。
3. 测试关联样品、方法、条件、指标与原始文件。
4. 处理结果保留输入、列映射、分组、步骤及参数。
5. Origin 工程及图像关联参与记录，保留成果版本。

## 多源数据统一

实验、模拟与文献数据应保留来源类型。统一材料名称、物理量、单位与质量状态后再做比较；不将模拟值、文献提取值和实测值混作同一来源。

## 版本、权限与备份

对已发生实验保留历史快照，对外部修改后的成果手动更新版本。模板共享、原始数据读取及导出分别授权。日常工程与重要实验资料按实际存储和实验室规则备份。

## 从积累到复用

先完成[实验数据收集](./experiment-data)，再按[数据中心](./data-center)建设状态汇聚记录。LLM/RAG 与 ML 能力将使用获准范围内、经过核对的领域数据。
