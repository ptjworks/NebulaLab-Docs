# 文献数据收集（待完善）

本模块待完善。计划将文献来源、结构化数据与研究对象关联，为领域知识检索和实验方案整理提供可核对依据。

## 预期页面内容

| 内容 | 需要准备的资料 |
| --- | --- |
| 文献信息 | 题名、作者、年份、期刊、DOI 或来源链接 |
| 原文与位置 | 可使用的原文、页码、图表或段落位置 |
| 提取信息 | 材料、配方、工艺、测试条件与性能数据 |
| 核对状态 | 提取方式、人工检查、单位换算和异常说明 |

## 规划流程

收集文献与来源 → 识别或提取目标信息 → 人工核对原文与单位 → 保存结构化记录 → 建立文献与实验数据的关联。

批量抓取、识别方式、解析范围和导入界面尚待完善，不将这条目标流程当作现有可执行操作。

## 数据核对

保留性能数据所对应的测试条件与原文位置。自动提取的内容需检查材料名称、数量级、单位和图表含义，保留无法确认的信息，不用补写值代替缺失依据。

## 与知识助手的关系

经核对的文献数据将支持[LLM+RAG知识助手](./llm-rag)检索、引用来源和整理专业领域实验方案报告。
