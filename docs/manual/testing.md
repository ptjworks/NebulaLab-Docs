# 管理表征及性能测试

每条测试记录属于具体样品。结果指标、原始曲线、图像和仪器文件一起提供判断依据；一个样品可以对应多个项目与重复测试。

## 页面与字段

| 内容 | 填写要点 |
| --- | --- |
| 样品与项目 | 样品编号、测试项目或方法 |
| 测试条件 | 仪器、日期、操作人及适用环境条件 |
| 指标 | 数值、单位、质量状态与计算条件 |
| 原始文件 | 曲线、光谱、图像、仪器导出文件等 |
| 重复与异常 | 分别保存重复测试，标明排除原因 |

## 操作步骤

1. 在样品的测试与表征入口添加记录，核对样品身份。
2. 选择测试项目，填写方法、仪器、日期与测试条件。
3. 录入已确认指标及单位，记录指标所对应的计算条件。
4. 添加原始文件，检查文件名、列含义及测试对象。
5. 保存记录；重复测试或不同测试项目分别录入。

## 指标示例

拉伸可记录强度、模量和断裂伸长率，并保留应力—应变曲线。红外记录光谱及需要提取的峰信息；热重残重需注明温度与气氛。不同测试的指标不同，不用一个汇总数值替代全部原始依据。

## 转入处理

选取所需测试文件添加到[数据统一后处理](./processing)，核对列、单位与分组。上传文件与录入指标是不同动作，自动提取范围取决于实际文件格式与流程支持。
