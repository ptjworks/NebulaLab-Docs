# Machine Learning (ML)材料智能体

**建设状态：规划中。目的：从数据中学习规律，对样品进行性能预测与逆向设计。**

基于专业数据库开发和验证材料领域模型，支持虚拟筛选、多目标优化及实验方案设计。以下为目标流程，具体页面和可用模型以后续版本为准。

## 预期页面内容

| 区域 | 目标内容 |
| --- | --- |
| 数据集 | 数据范围、来源、特征、标签、单位与质量 |
| 模型 | 任务类型、训练方法、版本与适用范围 |
| 验证 | 数据划分、评价指标、误差与不确定性 |
| 设计任务 | 目标性能、组成或工艺约束、候选范围 |
| 实验反馈 | 候选方案、真实测试结果及差异记录 |

## 目标流程

1. 选择获准数据，检查缺失值、单位、重复样品与测试条件。
2. 确定特征与目标性能，保留数据版本及来源。
3. 训练模型并在独立数据上验证，记录误差及适用范围。
4. 对候选材料进行性能预测、虚拟筛选或多目标优化。
5. 按目标性能与约束生成候选实验方案，研究者选择后执行。
6. 将实测结果与预测分开保存，对比偏差并回流数据库。

## 预测与逆向设计

性能预测从已知组成或条件估计性能；逆向设计从目标性能和约束出发搜索候选材料与条件。两者均需模型适用范围及验证结果支持，模型建议通过实验再验证。

## 与平台愿景的关系

配方设计 → 实验执行 → 数据沉淀 → 自动分析 → 模型学习 → 推荐实验 → 再验证。新实验结果继续补充领域数据，支持下一轮模型和方案迭代。
