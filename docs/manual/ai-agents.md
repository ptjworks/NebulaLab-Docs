# 智能能力建设方向

平台将智能能力分为两条方向，均处于规划阶段。分别查看对应手册，了解目标页面、所需数据与预期流程。

## LLM+RAG知识助手

目的：让人更高效地使用已有知识。结合专业数据库检索相关实验数据与相似实验方案，整理带来源的领域实验方案报告。见[LLM+RAG知识助手](./llm-rag)。

## ML材料智能体

目的：从数据中学习规律，支持性能预测、虚拟筛选、多目标优化与逆向设计，形成候选方案—实验验证—数据回流的迭代流程。见[ML材料智能体](./ml-agent)。

## 共同数据基础

依托已沉淀的专业数据库，检查来源、数据质量与访问权限。知识检索与模型学习承担不同任务，具体可用页面、算法和交付状态以发布版本为准。
