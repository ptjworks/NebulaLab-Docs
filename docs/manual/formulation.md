# 计算实验配方

配方页面将物料、比例、计算规则与目标用量联系起来。基础配方用于复用，样品配方保存本次实际采用的组成。

## 页面与输入

| 区域 | 关注内容 |
| --- | --- |
| 物料选择 | 对应物料、牌号、批次及计算所需物性 |
| 计算输入 | 目标总量、组分比例、规则输入及单位 |
| 用量结果 | 各组分计算量、总量与需要核对的偏差 |
| 版本与关联 | 基础配方版本、样品草稿及实际用量 |

## 操作步骤

1. 创建或打开基础配方，选择参与实验的物料。
2. 选择适用的计算规则，输入比例与目标总量，检查质量分数或其他比例的定义。
3. 执行计算，核对各组分用量、单位、合计与计算前提。
4. 保存基础配方版本，供本次或后续样品引用。
5. 创建样品时引用对应版本，确认实际用量；有调整时记录原因。

## 示例核对

对于总量 100 g、填料质量分数 20% 的两组分示例，填料为 20 g、基体为 80 g。此处只是质量分数示例，其他体系需按实际规则、固含量及材料条件计算。

## 版本与制备的关系

修改样品配方草稿不直接覆盖基础配方。确认制备时保留配方及过程快照，后续基础配方更新不应改写已经发生的实验依据。
