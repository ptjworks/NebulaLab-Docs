# 组建物料库

物料库负责记录材料本身的身份、物性、批次与来源，供配方及样品引用。本次使用量保存在配方和样品组成中。

## 页面与记录组成

在软件的物料库中查找和维护记录。物料详情包含名称与识别信息、适用物性、供应商与批次、资料附件。具体字段随材料类别和安装版本有所不同。

| 内容 | 记录要点 |
| --- | --- |
| 身份信息 | 名称、物料代码、化学品识别信息或自定义牌号 |
| 物性 | 密度、摩尔质量、固含量、尺寸等适用值，注明单位 |
| 来源 | 供应商、牌号、批次与物性资料来源 |
| 附件 | 规格书、检测资料或其他可核对文件 |

## 操作步骤

1. 进入物料库，先检索现有记录，核对是否为同一牌号与批次。
2. 新建物料。常见化学品可查询 PubChem；查询不到的材料自行录入。
3. 填写适用物性与单位，对资料来源不明确的数值先核实。
4. 补充供应商、批次及资料附件，核对后保存。
5. 在配方中选择该物料，检查物性是否满足当前计算规则。

## 保存后检查

确认记录可被检索，名称与批次能区分；检查密度、固含量等输入所用的单位。修改资料时保留来源与版本依据，避免将不同批次混为一条实际实验记录。
