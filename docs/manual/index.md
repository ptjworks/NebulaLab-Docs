# 用户手册

本手册与[产品页面](../products/)的六类具体功能对应。实验数据收集已拆分为七个操作章节，每章说明记录内容、使用步骤、检查要点，并关联帮助中心同名学习资源。

| ML材料智能体 | [性能预测、筛选与逆向设计](./ml-agent) | 规划中 |

## 实验数据收集的七个环节

1. [组建物料库](./materials)：材料身份、物性、批次和来源。
2. [计算实验配方](./formulation)：选择物料、设置输入、计算用量并保存版本。
3. [记录实验过程](./preparation)：制备步骤、参数、图像与确认快照。
4. [管理表征及性能测试](./testing)：样品、测试条件、指标和原始文件。
5. [沉淀专业数据库](./database)：完整性检查、来源及版本关联。
6. [数据统一后处理](./processing)：列映射、分组、处理方法、模板和批量应用。
7. [Origin 批量出图](./origin)：图形模板、数据交接、工程和成果关联。

## 按任务开始

记录完整实验时阅读[实验全流程](./experiment-workflow)。只处理一份仪器文件时，可先阅读[数据准备](./data-preparation)和[基础处理教程](../tutorials/basic-processing)。

已有的[实验管理](./experiment-management)、[样品管理](./sample-management)和[处理工作流](./workflow)文档保留为进一步说明。

## 视频与学习资源

进入[帮助中心的学习资源](../tutorials/)，按同名模块查看操作文档和视频状态。视频待拍摄，完成后将补充到对应位置；规划中的功能先说明目标流程，暂不提供虚构操作或播放入口。

## 数据、版本与权限

[全链路数据管理](./data-management)介绍身份、来源、版本及权限；[核心概念](./concepts)、[社区与模板](./community)及[授权说明](./pro)用于补充理解。

软件能力以安装版本、服务配置与数据权限为准。统一数据中心、LLM/RAG 及 ML 建设状态见对应章节。Origin 修改需要手动更新成果版本；实验室上报与受控读取不等同于所有业务记录实时双向同步。
