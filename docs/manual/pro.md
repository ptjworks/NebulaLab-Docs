# 授权与权限

软件功能许可、成员角色和科研资源权限是三件不同的事。获得功能许可，不会自动成为管理员；具有管理员角色，也不代表能读取所有私有成果。

## 软件功能许可

现有发布版与开发中版本处于授权机制调整期，请以安装版本中显示的状态和对应发布说明为准。

旧授权机制区分基础版和 Pro：基础版保留基础数据处理和单样品 Origin 导出；Pro 增加 Origin 批量及模板导出、处理预设、流程及绘图模板、配方工作台、实验库和数据集导出等能力。

新的授权方向转为实验室账号驱动，按已授权、未授权和相关只读状态管理使用。不要把旧版激活流程当作所有版本的统一操作步骤。

## 实验室成员与设备

下载安装后，按软件内流程登录实验室账号或提交加入申请。成员与设备是否获准接入，由实验室规则决定；功能是否可用还需核对软件版本、许可及服务器能力。

## 角色与数据权限

| 概念 | 决定什么 |
| --- | --- |
| 功能许可 | 是否可以使用相应软件功能 |
| 成员和设备资格 | 是否获准接入实验室服务 |
| 管理角色 | 是否可以执行获准的成员、设备、词条等治理操作 |
| 对象权限 | 是否可以查看、导出、修改或发布某份数据或资源 |

普通成员可在满足许可、来源和对象权限时保存本地成果、上传自己的合格数据。测试或图像包含他人数据时，允许查看或导出，不一定允许再次发布。

## 上传不等于共享

样品共享与成果权限分别判断。当前云端分析成果采用创建者私有规则，不因上传、关联某个样品或具备管理角色，就自动向全组开放。

团队处理模板、Origin 模板、科研脚本等内部资源，按授予的权限开放给相应成员。
