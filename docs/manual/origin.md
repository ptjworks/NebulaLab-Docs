# Origin 批量出图

将分组处理结果交接 Origin，复用图形模板与主题，并在支持成果归档的版本中关联参与样品、测试及输入来源。

## 使用前准备

检查本机 Origin 安装与自动化环境，准备适用的模板和主题。先用少量示例文件确认列映射、单位与模板兼容，再处理完整数据组。

## 操作步骤

1. 在数据工作区选择要导出的分组与结果，确认 X/Y 列。
2. 按实际功能选择 Origin 交接方式、图形模板与主题。
3. 执行交接，在 Origin 中核对曲线数量、图例、坐标轴、单位与分组。
4. 完成图形调整，保存工程文件与正式图像。
5. 在支持成果归档的版本中关联参与样品及测试，保留输入来源。

## 批量出图检查

| 检查项 | 需要确认 |
| --- | --- |
| 模板 | 适合同类数据，列结构与图形类型匹配 |
| 分组 | 每条曲线对应正确样品与变量 |
| 表达 | 轴标签、单位、图例及范围正确 |
| 归档 | 工程、图像、输入来源和成果版本齐全 |

## 外部修改与成果版本

在 Origin 修改工程后先保存，再回到成果入口手动更新版本，选择已编辑的 `.opju` 或 `.opj`，按需添加正式图像并核对参与样品。Origin 修改不会实时写入配方备注。

## 常见问题

如果无法直接交接，先核对 Origin 环境、文件权限与模板兼容。需要反馈时提供软件版本、最小复现步骤与脱敏示例。完整关系见[实验全流程](./experiment-workflow#origin)。
