# 沉淀专业数据库

将已有物料、配方、样品、测试与成果组织为可检索、可追溯的领域记录，是后续数据中心、知识助手和材料模型的数据基础。

## 专业数据库与数据中心的区别

专业数据库强调领域内容、字段与来源关系；[数据中心](./data-center)负责多源数据的汇聚、修订、检索和访问管理。现阶段先完善本地实验记录，统一数据中心按建设状态推进。

## 记录完整性检查

1. 检查物料身份、批次、物性和来源是否可核对。
2. 核对配方版本、样品实际用量及制备快照。
3. 补齐步骤、工艺参数、过程图像与测试条件。
4. 检查测试指标的数值、单位、质量状态和原始文件。
5. 保存处理步骤、输入文件、Origin 工程及成果版本的关联关系。

## 数据组织建议

| 记录 | 建议保留的关联 |
| --- | --- |
| 物料 | 批次、物性来源、配方引用 |
| 样品 | 配方版本、实际组成、步骤与图像 |
| 测试 | 样品、方法、指标、原始文件 |
| 处理成果 | 输入来源、步骤与参数、工程和版本 |

## 检索与共享

在当前版本可用入口按样品、测试或指标查找记录，验证是否能由成果回到原始依据。需要上报实验室服务时，先核对提交资格与资源权限。共享方法、查看原始数据和导出分别判断，不将上传视为自动公开。
