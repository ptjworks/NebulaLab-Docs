# 实验管理：物料与配方计算

实验管理把材料信息、计算规则与具体实验用量联系起来。先建立可复用的物料和基础配方，再为每个样品保存实际采用的配方版本。

## 建立物料库 {#materials}

1. 打开物料库，新建物料，填写名称与识别代码。
2. 常见化学品可查询 PubChem；复合材料、牌号材料或查询不到的物料可自行录入。
3. 按材料类别补充摩尔质量、密度、固含量、尺寸等适用物性，写明单位与来源。
4. 记录供应商、牌号和批次，补充可用的资料附件，核对后保存。

物料库描述“这是什么材料”。本次使用多少，记录在配方与样品组成中。不同批次的差异也应保留，避免把材料名称相同当成实验条件完全相同。

## 计算实验配方 {#formulation}

1. 选择参与实验的物料，创建基础配方或打开已有版本。
2. 设置目标总量、比例及适用计算规则，检查输入单位。
3. 执行计算，核对各组分的用量和合计；计算结果需要研究者确认。
4. 保存基础配方版本，供后续样品引用。
5. 为本次样品核对实际用量，必要时调整样品配方草稿，并注明偏差。

例如比较不同填料质量分数时，可保持基体体系、总量和制备条件一致，为每一组保存独立样品记录。软件按给定规则计算用量，实验设计是否构成单变量对照仍需研究者确认。

## 配方与样品如何衔接

基础配方用于复用，样品引用对应版本并形成自己的草稿。样品草稿的调整不直接覆盖基础配方。确认制备后保存的快照用于追溯历史依据，不随基础配方的后续修改改写。
