# Development direction {#发展方向}

Nebula Lab connects materials, formulations, preparation, tests, processing, Origin and results. [Official release notes](https://github.com/TshyGO/NebulaLab-Releases/releases) define delivery; implemented code does not itself confirm installer or production acceptance.

## Workflows under continuous improvement {#持续完善的工作路径}

- Maintain materials and formulations; record preparation and tests.
- Link raw files, metrics, processing and result sources.
- Reuse methods for similar data and transfer to Origin.
- Save result versions and submit or retrieve authorized laboratory data.
- Improve performance, authorization, upgrades and recovery.

Origin is the analysis and plotting handoff. Archiving and traceability continue afterwards; external project edits require manual updates.

## Future intelligent capabilities {#后续-ai-方向}

These are planned, not delivered features, with no committed delivery dates:

1. **Literature discovery:** collect relevant publication leads.
2. **Weekly reports and slides:** organize team reports for authorized administrator review.
3. **Agent collaboration:** access authorized research data with identity checks and source records.

See [intelligent capability plans](../ai/).

## Extensions {#扩展方向}

More reusable preparation modules may reduce hard-coded work for new research directions. Cross-device recovery still needs identity, permissions and migration rules; it is not existing real-time synchronization.
