# Intelligent capabilities: development direction {#智能能力建设方向}

The platform plans two intelligent capabilities. Their manuals describe intended pages, required data and workflows.

## LLM + RAG knowledge assistant {#llm-rag知识助手}

Help people use existing knowledge efficiently: retrieve experiment data and similar proposals from domain databases and prepare reports with citations. See the [LLM + RAG assistant](./llm-rag).

## ML materials agent {#ml材料智能体}

Learn patterns for prediction, virtual screening, multi-objective optimization and inverse design, iterating through recommendations, experimental validation and data feedback. See the [ML materials agent](./ml-agent).

## Shared data foundation {#共同数据基础}

Both use accumulated domain databases with reviewed sources, quality and permissions. Retrieval and model learning perform different tasks. Release notes define actual pages, algorithms and availability.
