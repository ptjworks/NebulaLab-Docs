# Data center (under construction) {#数据中心-搭建中}

The unified data center is being built to aggregate experiment, simulation and literature data while retaining structured fields, versions, sources and permissions. Laboratory instructions below depend on the installed version and actual server configuration. Unified simulation and literature ingestion is still in development.

The center holds structured laboratory records, related files and revisions. Daily recording and calculation take place on the desktop; laboratory services provide submission, search, previews and controlled retrieval.

## Local work and laboratory deployment {#本地工作与实验室部署}

The desktop maintains experiment records, processes data and saves projects. Teams connect to their actual laboratory deployment; maintainers must confirm server setup and available features.

Local projects, long-term experiment databases and server records have different roles. The center does not imply real-time two-way synchronization of all records.

## Submit experiment data {#上报实验数据}

1. Follow the in-app laboratory connection process; check account, device and membership.
2. Select records and verify formulation, sample, test and file completeness.
3. Confirm the content and submit when eligibility and permissions allow.
4. Review submission status and revisions, retaining traceable sources.

## Search and retrieve {#检索与获取}

1. Search by available sample, test or metric criteria.
2. Preview authorized records and files; check sources and versions.
3. Retrieve permitted files and add them to processing as needed.
4. Check instruments, units and conditions before comparing historical data.

## Access permissions {#访问权限}

Feature licensing, administrator roles and resource access are evaluated separately. Uploading is not group-wide sharing; viewing, exporting and republishing require their respective permissions. Current cloud results are private to their creator; administrator status does not override ownership.

See [licensing and permissions](./pro).
