# Experiment management: materials and formulations {#实验管理-物料与配方计算}

Connect material information, calculation rules and actual quantities. Build reusable materials and base formulations, then save the version actually used for each sample.

## Build a material library {#materials}

1. Open the library, create a material and enter its name and identifier.
2. Query PubChem for common chemicals; manually enter composites, grade-specific or unlisted materials.
3. Add applicable molar mass, density, solids content or dimensions with units and sources.
4. Record supplier, grade and batch, attach documentation, review and save.

The library describes what a material is. Quantities belong to formulations and sample compositions. Preserve batch differences rather than assuming identical names mean identical conditions.

## Calculate experiment formulations {#formulation}

1. Select materials and create a base formulation or open a version.
2. Set total quantity, ratios and rules; check units.
3. Calculate and verify component amounts and totals.
4. Save the base version for samples to reference.
5. Confirm actual sample quantities, adjust the sample draft if needed and document deviations.

For filler mass-fraction comparisons, keep matrix, total quantity and preparation conditions consistent and save separate samples. The software calculates from rules; the researcher confirms whether the design controls a single variable.

## Connect formulations and samples {#配方与样品如何衔接}

Samples reference reusable base versions and have their own drafts. Sample edits do not overwrite the base. Confirmed preparation snapshots preserve historical evidence despite later base changes.
