# Record experiment processes {#记录实验过程}

A sample connects the experiment process. Keep its formulation, steps, parameters and images together so later tests can be traced to the original conditions.

## Page and record structure {#页面与记录组成}

Sample details contain an identifier and name, base formulation and actual composition, preparation steps, process notes and attachments. Steps are primarily text in the current version; some composition and process fields are structured.

## Operating steps {#操作步骤}

1. Create a sample with a name and identifier that distinguish this experiment and batch.
2. Select the base formulation version and check actual components and amounts.
3. Record mixing, molding, curing and other steps in execution order, including adjustments.
4. Record applicable temperature, time, pressure and speed, with units.
5. Add process and preparation images through available attachment or appearance-record features. Identify the step, time and observation.
6. Check the record against the actual experiment, confirm preparation and retain its snapshot.

## Combine images with parameters {#图像与参数如何配合}

Each image should identify its sample, step and observed phenomenon. Photos support the record; saving an image does not automatically extract parameters or replace written and structured information.

## Corrections and traceability {#纠正与追溯}

Use the installed version's copy, revision or version operations to correct confirmed records. Explain the change and retain the original snapshot rather than using a new formulation to describe an old experiment.
