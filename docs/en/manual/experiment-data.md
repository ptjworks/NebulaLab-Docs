## Where to start {#建议起点}

For an entire experiment, begin with materials and formulations, then create samples, preparation and test records. For instrument files, begin directly with post-processing and complete sample and source relationships afterwards.

## Close the data loop {#数据如何闭环}

Keep formulations, preparation, samples and tests linked. Retain processing parameters and raw data. After plotting in Origin, archive the project, images and sources in supported versions; manually update versions after external edits.

See the [product demonstration](../products/#experiment-data) or [manual overview](./).
