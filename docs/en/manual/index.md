# User manual {#用户手册}

This manual follows the six feature groups on the [product page](../products/). Experiment collection has seven operating chapters, each covering records, steps, checks and matching Help center resources.

## Features and manuals {#功能与手册对应}

| Feature | Instructions | Status |
| --- | --- | --- |
| Experiment data collection | [Seven operations](./experiment-data) | Depends on installed version |
| Simulation data collection | [Planned pages and preparation](./simulation-data) | In development |
| Literature data collection | [Sources, extraction and review](./literature-data) | In development |
| Data center | [Aggregation, search, revisions and access](./data-center) | Under construction |
| LLM + RAG assistant | [Knowledge retrieval and proposal reports](./llm-rag) | Planned |
| ML materials agent | [Prediction, screening and inverse design](./ml-agent) | Planned |

## Seven experiment operations {#实验数据收集的七个环节}

1. [Build a material library](./materials): identity, properties, batches and sources.
2. [Calculate formulations](./formulation): select materials, calculate amounts and save versions.
3. [Record experiment processes](./preparation): steps, parameters, images and snapshots.
4. [Manage characterization and tests](./testing): samples, conditions, metrics and raw files.
5. [Build a domain database](./database): completeness, sources and version relationships.
6. [Standardize post-processing](./processing): column mapping, groups, methods, templates and batches.
7. [Batch plotting in Origin](./origin): templates, transfer, projects and result links.

## Start with your task {#按任务开始}

Read the [full workflow](./experiment-workflow) to record an entire experiment. For instrument files, begin with [data preparation](./data-preparation) and the [basic walkthrough](../tutorials/basic-processing).

Additional explanations remain available in [experiment management](./experiment-management), [sample management](./sample-management) and [processing workflows](./workflow).

## Videos and learning resources {#视频与学习资源}

Visit [Help center learning resources](../tutorials/) for matching guides and video status. Videos will be added after recording. Planned features describe intended workflows rather than offering nonfunctional controls.

## Data, versions and permissions {#数据、版本与权限}

[End-to-end data management](./data-management) covers identity, sources, versions and access. [Core concepts](./concepts), [community and templates](./community) and [licensing](./pro) provide additional context.

Capabilities depend on the installed version, service configuration and permissions. See each chapter for data center, LLM/RAG and ML development status. Origin edits require manual version updates; laboratory submissions and retrieval do not imply real-time two-way synchronization of all records.
