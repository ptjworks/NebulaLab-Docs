# End-to-end data management {#全链路数据管理}

Organize experiment records and files in consistent relationships. Retain sources, units, versions and permissions so data can be found, understood, checked and reused.

## Identity and naming {#身份与命名}

Materials, formulations, samples, tests and results need distinguishable identifiers. File names may include sample ID, test, date and replicate number, but actual record relationships remain authoritative.

## Sources and relationships {#来源与关系}

1. Materials retain batches, properties and documentation sources.
2. Samples link actual formulation versions and preparation snapshots.
3. Tests link samples, methods, conditions, metrics and raw files.
4. Processed results retain inputs, column mapping, groups, steps and parameters.
5. Origin projects and images link participating records and result versions.

## Multiple data sources {#多源数据统一}

Preserve whether data comes from experiments, simulation or publications. Harmonize names, quantities, units and quality status before comparing. Keep predictions, extracted literature values and measurements distinguishable.

## Versions, permissions and backups {#版本、权限与备份}

Retain historical experiment snapshots and manually version externally edited results. Authorize template sharing, raw data retrieval and export separately. Back up projects and important experiment information according to storage and laboratory rules.

## From accumulation to reuse {#从积累到复用}

Complete [experiment records](./experiment-data), then aggregate them according to [data center](./data-center) availability. LLM/RAG and ML will use reviewed, authorized domain data.
