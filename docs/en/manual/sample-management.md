# Sample management: process parameters and images {#样品管理-实验过程参数与图像}

Each physical sample links its formulation, preparation steps, parameters, images, raw test files and later analysis results.

## Record preparation {#preparation}

1. Create a sample, enter its ID and name and select a base version.
2. Check quantities and record adjustments and reasons.
3. Enter actual mixing, molding, curing and other steps in order.
4. Record applicable temperature, time, pressure and speed with units.
5. Add process and preparation images through available attachments or appearance records. Identify step, time and observation.
6. Review, confirm preparation and retain the formulation and process snapshot.

Steps are primarily text, with some structured composition and process fields. Images are evidence, not automatic parameter extraction. Use copy or version operations to change locked records while preserving originals.

## Link characterization tests {#testing}

1. Add a test in the sample's testing and characterization area.
2. Enter method, instrument, date, operator and conditions.
3. Enter metrics, units and quality, such as tensile strength, modulus or residual mass under stated conditions.
4. Link raw instrument files, curves and images.
5. Save replicates separately and explain excluded results.

Keep metrics and raw files separately. Infrared tests retain spectra and peaks; thermogravimetric residual mass requires temperature and atmosphere. Different tests need different metrics; one number cannot replace the full evidence.

## From tests to processing and results {#从测试到处理及成果}

Add files to [processing](./workflow), check columns, groups and units, and apply validated workflows. Versions with archiving can save Origin projects and images linked to samples.

Manually update result versions after Origin edits. See [Origin and result relationships](./experiment-workflow#origin).
